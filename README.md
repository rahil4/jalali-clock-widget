# ساعت شمسی — ویجت اندروید

ویجت صفحهٔ اصلی اندروید با ساعت (ساعت بالا، دقیقه پایین) در قاب مستطیل عمودی، تاریخ شمسی زیر قاب و پس‌زمینهٔ شفاف.

- رنگ و گردی گوشهٔ قاب از تنظیمات ویجت قابل تغییر است (لمس ویجت یا تنظیم هنگام افزودن).
- ساعت (فونت کلاسیک Gilda Display) با `TextClock` سیستم به‌روز می‌شود (بدون مصرف باتری اضافه)؛ تاریخ با تغییر روز دوباره محاسبه می‌شود.
- اندازهٔ ویجت قابل تغییر است و قاب متناسب با آن تغییر می‌کند.

## ساخت
`./gradlew testDebugUnitTest assembleDebug` — خروجی: `app/build/outputs/apk/debug/app-debug.apk` (در GitHub Actions به‌عنوان artifact هم ساخته می‌شود).
